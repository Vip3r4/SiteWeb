Protocoles

Voici le protocole à appliquer obligatoirement pour chaque code :


  • Le Code Jaune est déclenché si un seul SCP Hostile est déconfiné. Le personnel doit se mettre à l'abri en attendant que le personnel militaire reconfine le SCP.
    ↪︎ Le Code Jaune peut être désactivé si le SCP est mort ou reconfiné.
  • Le Code Rouge est déclenché lorsque deux SCP Hostiles ou plus sont déconfinés. L'ensemble du personnel de la fondation doit être escorté par le personnel militaire vers la surface et extrait du site.
    ↪︎ Le Code Rouge ne peut pas être désactivé.
    ↪︎ Respawn FIM et Chaos jusqu'à la fin de la partie.
  • Le Code Noir est déclenché si quatre SCP Hostiles ou plus sont déconfinés. Déclenchement automatique de l'Alpha Warhead, qui ne peut pas être désactivé.
    ↪︎ Le Code Noir ne peut pas être désactivé.
