Commandes

Voici la liste des commandes disponibles en jeu


Les commandes se saisissent dans votre console client ( Touche %/ù par défaut )

  • .sacrifice : Pour allumer le Femur Breaker.
  • .femuractivate : Pour activer le Femur Breaker.
  • .reconf106 : Pour tuer SCP-106 avec le Femur Breaker.
  • .push : Pousse la personne que vous regardez.
  • .punch : Frappe la personne que vous regardez.
  • .cuff : Vous permet de menotter quelqu'un de votre équipe.
  • .deconf106 dans le confinement de SCP-106 avec une carte en main : Déconfine SCP-106 (Au bout de 15 secondes).
  • .hack dans la salle des serveurs avec votre carte en main : C.A.S.S.I.E. deviendra SCP-079.
  • .reconf dans une salle de confinement, ou dans une salle avec accréditation : Permet de vous reconfiner.
  • .backup dans la salle des serveurs : Envoie une escouade de renfort sur le site ( Cooldown de 300 sec ).
  • .decontamination dans la salle des serveurs : Active la décontamination de la LCZ.
  • .spec / .spectateur : Permet de devenir spectateur si vous ne souhaitez pas être SCP.
  • .clean : Nettoie le cadavre le plus proche de vous.
  • .heal avec un kit en main et en visant un joueur: Soigne la cible de 75pv.
  • .promote en visant un joueur: Pour promouvoir un membre du personnel.
  • .demote en visant un joueur: Pour rétrograder un membre du personnel.
  • .healscp avec un kit en main et en visant un SCP: Soigne la cible de 300pv.
  • .bn nom / .badgename nom : Vous permet de changer le nom de votre badge (Voir règlement Patreon afin d'éviter les abus).
  • .bc couleur / .badgecolor couleur : Vous permet de changer la couleur de votre badge.
  • .bc list : Permet de voir la liste des couleurs disponibles.
  • .dnumber numéro / .dn numéro : Vous permet de changer votre numéro de Class-D.
